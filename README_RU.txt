LIVE STREAM SIMULATOR — ИНСТРУКЦИЯ (РУССКИЙ)

Что внутри
- index.html — интерфейс симулятора, видеопревью с камеры телефона и чат с 20 вымышленными персонажами.
- server.js — сервер, который вызывает настоящий OpenAI API и не раскрывает ключ в браузере.
- package.json — команда запуска.

ВАЖНО
- Счётчик зрителей и сообщения — симуляция. Это не реальные зрители YouTube.
- В режиме «Шаблоны» ИИ API не нужен; сообщения создаются на устройстве.
- Для настоящих ответов требуется сервер, API-ключ OpenAI и может потребоваться оплата за использование API. Попроси родителя/опекуна помочь с аккаунтом, ключом и лимитом расходов.
- Никогда не отправляй API-ключ в чат, не добавляй его в HTML и не публикуй его в файлах проекта.
- Если сервер доступен из интернета, не делай ссылку публичной без защиты и лимитов: иначе другие люди могут расходовать твой API.

ЗАПУСК СЕРВЕРА (нужно один раз настроить на компьютере или хостинге с Node.js 18+)
1. Загрузи файлы проекта на доверенный сервер с Node.js.
2. В настройках сервера добавь секретную переменную окружения:
   OPENAI_API_KEY = твой API-ключ
   При необходимости можно указать OPENAI_MODEL = gpt-5.4-mini
3. Запусти команду: npm start
4. Открой HTTPS-адрес сервера в Chrome на Android.
5. Нажми «Включить камеру» и разреши доступ.
6. Чтобы использовать настоящий ИИ, включи переключатель «Использовать настоящий ИИ» и нажми «Запустить чат».

КАМЕРА
Камера работает через браузерный запрос разрешения. В большинстве браузеров доступ к камере требует защищённого контекста HTTPS (или localhost). Изображение камеры отображается локально на странице и не отправляется на API этим приложением.

ПРИМЕЧАНИЕ
HTML можно открыть самостоятельно для просмотра интерфейса, но подключение настоящего ИИ сработает только при наличии запущенного backend-сервера на том же адресе либо при указании адреса своего backend в поле подключения.

ДОПОЛНИТЕЛЬНАЯ ЗАЩИТА ДЛЯ ПУБЛИЧНОГО АДРЕСА
Перед тем как открывать сервер в интернет, настрой ещё один секрет:
   SIMULATOR_ACCESS_CODE = длинный непредсказуемый код доступа
Затем введи этот код в поле «Код доступа» приложения. Это не API-ключ OpenAI.
Не публикуй код доступа и адрес сервера без необходимости. Ограничение запросов в server.js — дополнительная защита, но не замена приватному доступу и лимитам расходов API.
